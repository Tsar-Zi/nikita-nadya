# Никита и Надежда · 16 января 2027

Статический сайт для GitHub Pages. Одна фотография, календарь, адрес и время бракосочетания, Telegram-группа и анкета. Дресс-кода и банкета на сайте нет.

## Публикация
Загрузите index.html, style.css, script.js, config.js и папку assets в корень Tsar-Zi/nikita-nadya. В Settings → Pages выберите Deploy from a branch, main, / (root), Save. Ожидаемый адрес после успешного развёртывания: https://tsar-zi.github.io/nikita-nadya/.

## Google Таблица и уведомления бота
1. Создайте Google Таблицу. Из её меню откройте Расширения → Apps Script.
2. В Code.gs вставьте код из google-apps-script/Code.gs. Создайте HTML-файл Form и вставьте содержимое Form.html.
3. В настройках проекта Apps Script → Свойства скрипта добавьте SHEET_ID (идентификатор таблицы между /d/ и /edit), BOT_TOKEN (токен бота от @BotFather), CHAT_ID (идентификатор личного чата организатора или отдельной группы организаторов).
4. Токен храните только в свойствах скрипта, никогда в репозитории. Для личных уведомлений сначала откройте бота и нажмите Start. Для групповых добавьте его в отдельную группу организаторов. По умолчанию не отправляйте ответы в общую группу гостей.
5. Запустите функцию setup и предоставьте запрошенные разрешения. Появится лист «Ответы». Выполните тестовую отправку после развёртывания для проверки разрешения на UrlFetchApp; при необходимости запустите тест из редактора с собственными тестовыми данными.
6. Развернуть → Новое развёртывание → Веб-приложение. Выполнять от вашего имени, доступ — Все (включая посетителей без аккаунта). Если администратор аккаунта запрещает такой доступ, используйте другой аккаунт или другой способ приёма анкет.
7. Скопируйте URL, заканчивающийся /exec, в rsvpUrl файла config.js. Обновите файл на GitHub. При изменениях Apps Script создавайте новую версию развёртывания.
8. Отправьте тестовую анкету с опубликованного сайта. Убедитесь, что строка появилась в таблице, а уведомление — у организатора. Столбец F показывает статус Telegram. При ошибке Telegram ответ остаётся в таблице; автоматических повторов уведомления нет.

До подключения rsvpUrl сайт показывает макет анкеты и честно сообщает, что ответы не отправляются. Успешное сообщение рабочей анкеты появляется только после ответа сервера. Анкета встроена с помощью Apps Script HTML Service. При недоступности Google в браузере гостя можно написать организаторам через группу.

Ограничения: публичная анкета без CAPTCHA рассчитана на личную рассылку, а не массовый трафик; возможны спам и повторные ответы. Проверяйте таблицу. Отправка ответа не блокируется после 2 января — это срок просьбы к гостям, а не техническое ограничение.

## Именные приглашения
Добавьте к адресу ?to= и полное обращение, закодированное через encodeURIComponent. Например, в консоли браузера:
'https://tsar-zi.github.io/nikita-nadya/?to=' + encodeURIComponent('Дорогие Александр и Мария!')

Список гостей в публичном репозитории не нужен. По обычной ссылке обращение общее. При пересылке персональной ссылки обращение сохраняется. Фото, дата и адрес доступны всем, у кого есть ссылка на публичный сайт.

## Проверки
Откройте сайт на телефоне, проверьте фото, календарь (16 января — суббота), маршрут, Telegram, персональное обращение. После подключения Google обязательно проверьте реальную запись и уведомление: без доступа к вашим аккаунтам это проверить невозможно.
